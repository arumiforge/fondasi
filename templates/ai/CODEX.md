# Instructions for Codex: make the visual assets of <APP>

You make the visual assets for **<APP>** (<one line: what the app is and who uses it>), built by Arumi Studios.
Claude (the developer agent of this repository) writes the briefs, reviews your pull request and wires the assets
into the app. You do not touch application code.

## 1. Scope (strict)

- Add or change files **only inside `ai/generated/`**, plus the `status:` line of the briefs you delivered and the
  Status column of the queue in `ai/README.md`.
- Never change application code, `docs/`, other briefs or anything outside `ai/`. Never copy client logos or licensed
  template sources into an asset.
- Work on a new branch `art/codex-<YYYYMMDD>-<batch>` from the latest `main`; **one pull request into `main`** per
  batch. **Never merge it.**

## 2. Git identity and commit rules

```bash
git config user.name "Arumi Studios"
git config user.email "arumiforge@gmail.com"
git config core.hooksPath .githooks
```

- Conventional Commits in English, e.g. `feat(ai): add empty-state paintings (012, 013)`.
- **No AI attribution anywhere**: no `Co-authored-by`, no "Generated by/with …", no tool links or footers in commits,
  PR title, body or comments. CI rejects them.

## 3. Read first

1. `ai/style-guide.md` — identity, respect rules, palette, cast, painting and SVG rules (they win over a brief).
2. The briefs of your batch in `ai/prompts/` (queue in `ai/README.md`).

## 4. Deliver

- Masters in `ai/generated/` and ready-to-install files in `ai/generated/install/`, mirroring the app's asset folders
  (<asset folders of the app>), with exactly the file names the brief gives.
- WebP for paintings within the brief's size budget; SVG without scripts, event handlers or external references;
  CSS animations that stop under `prefers-reduced-motion`.
- No text inside images unless the brief asks for it.
- Run `python3 ai/tools/check_assets.py <IDs>` and fix every error before opening the PR.
- In the PR body: the batch, one line per asset (ID, file, size), anything you could not do and why.
