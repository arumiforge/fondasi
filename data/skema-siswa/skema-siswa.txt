STUDENT DATA SCHEMA - FIELDS AND OPTION LISTS (junior high school, Indonesia)

HOW TO READ
- Field line: NN. key | label | type | attributes
- key: suggested column/property name (snake_case). label: text shown to users (Indonesian).
- Types: text, integer, date (YYYY-MM-DD), select (one option), multiselect (several options),
  list (list of strings picked from an option list), table (repeating rows with sub-columns),
  region (cascading picker: province > regency/city > district > village > postal code),
  school (pick origin elementary school from a reference list, by name or NPSN), class (pick from the school's class list).
- required: must be filled. range=[min, max]. max_len: max characters. min_items/max_items: for list/table.
- options=KEY: values come from [KEY] in OPTION LISTS. Store the exact option text.
- other_allowed: add an "Lainnya" (Other) choice that opens a text input; store the typed text, never "Lainnya".
- exclusive="X": in a multiselect, option X cannot be combined with any other option.
- hide_if(cond): hide the field (and clear it) when cond is true. required_if(cond): required when cond is true.
- auto: not a visible input; filled by the picker of the field with the same unit.
- unit=NAME: fields with the same unit are edited/approved together as one block.

=== NOTES ===
- Region block (unit=wilayah): provinsi, kabupaten, kecamatan, desa, kode_pos picked together; kode_wilayah = official village code (auto).
- School block (unit=sekolah_asal): sekolah_asal = school name; sekolah_asal_npsn = its 8-digit NPSN (auto). Reference list covers SD, MI, SDLB.
- Format codes: kapital=UPPERCASE, proper=Proper Case, digit=digits only, nik/kk=16 digits, nisn=10 digits,
  wa=WhatsApp phone number, kode_pos=5 digits, tahun=4-digit year, tanggal=date.
- tanggal_lahir range is relative: age between 9 and 20 years. 'tahun_ini' = current year.
- Option "PNS/TNI/Polri" is a combined legacy value (from Dapodik exports); keep it alongside the split options.
- Option "Ibu Rumah Tangga (IRT)" is only offered for: pekerjaan_ibu.
- Option hint "Sepeda Motor": Dikendarai sendiri. Kalau dibonceng orang tua/wali, pilih Antar Jemput Ortu / Wali.
- Option hint "Anemia / Kurang Darah": Sangat umum pada remaja putri.
